Docs

Everything Offhook does, and where it stops.

Offhook is an iPhone terminal for people who run AI coding agents on their own servers: SSH and Mosh, native tmux and herdr, and agent state that reaches your lock screen. It has no account and no server of its own — it talks to your hosts and nothing else. These pages assume you already have a machine you can SSH into.

Two things worth knowing up front

Offhook never acts on your host without asking. It does not install packages silently, does not create sessions you did not ask for, and does not quietly attach a different multiplexer than the one you picked. When something is missing it says so and shows you the command.

There is no push server, so background updates stop. iOS suspends the connection once the app is in the background; agent state freezes at whatever it last saw and resumes when you come back. That is the price of having nothing in the middle, and it is the same for every transport.
