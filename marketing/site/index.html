Pick your multiplexer

The only iPhone terminal that speaks herdr.

tmux has run the world's servers for twenty years and Offhook renders it natively. But herdr is a multiplexer written for coding agents, and it turns the hardest part of this app — knowing what an agent is doing — from a guess into a fact.

tmux

mature · already on your box

  • Native control mode: sessions, windows, panes, all switchable
  • Attaches to what you already have, never restyles it
  • Agent status via a one-line hook install — accurate, but you install it
  • Scrollback, copy-mode and prefix keys behave the way you expect

herdr

built for coding agents

  • Agent state is a protocol field — nothing to install on the host
  • One pane, full phone width: no sidebar, no shrunken layout
  • Your phone's size never squeezes the window on your laptop
  • Scrolling is decided server-side — the app that grabbed the mouse gets a wheel
  • Isolated tasks: a git worktree, a workspace and an agent, from one sheet

Offhook speaks each one in its own words: herdr connections say workspace and tab and print herdr's real key bindings — because ⌃ b q lists panes in tmux and detaches in herdr, and an app that prints the wrong one drops your session. You pick per connection; nothing is switched behind your back.

Questions

The things people ask first.

Does it need anything installed on my server?

No — it's a standard SSH client out of the box. mosh, tmux and herdr are each optional. If one is missing, Offhook says so, shows the install command, and runs it only when you tap it. It never installs anything silently, and it never quietly attaches a different multiplexer than the one you picked.

How does it know an agent needs me?

On herdr, agent state is a protocol field — nothing to set up. On tmux, a one-line hook install (offered inside the app) lets agents report state directly; without it, Offhook falls back to reading output.

Which agents work with it?

Anything that runs in a terminal — Claude Code, Codex, and friends. Status detection is protocol-level on herdr and hook-based on tmux, so a new agent usually needs nothing from us.

Can it wake me up when the app is closed?

Honest answer: only while the session is alive on your device. Offhook has no push server — that's the trade for having nothing in the middle. iOS suspends the connection eventually, and state stops updating until you return.

Why "Offhook"?

Off-hook is the telephone state where the handset is up and the line is live — which is also what the icon is. And when your agents do the work, they take you off the hook. 中文名：摘机。
