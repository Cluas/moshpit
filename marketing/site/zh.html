选你的多路复用器

唯一会说 herdr 的 iPhone 终端。

tmux 撑了世界上的服务器二十年，Offhook 原生渲染它。但 herdr 是专为 coding agent 写的多路复用器， 它把这个 App 最难的那件事——知道 agent 到底在干嘛——从「猜」变成了「查」。

tmux

成熟 · 你机器上已经有了

  • 原生控制模式：会话、窗口、窗格都能切
  • 只附着到你已有的东西，绝不改它的样式
  • agent 状态靠一行命令装 hook——准确，但要你装
  • 回滚、复制模式、前缀键都按你熟悉的方式来

herdr

为 coding agent 而生

  • agent 状态是协议字段——主机上什么都不用装
  • 单窗格占满手机宽度：没有侧边栏，没有缩小版布局
  • 你手机的尺寸永远不会挤压笔记本上的窗口
  • 滚动由服务端判定——抢了鼠标的程序收到的是滚轮
  • 隔离任务：一个表单搞定 git worktree + workspace + agent

Offhook 用各自的语言说话：herdr 连接说 workspace 和 tab， 并且打印 herdr 真实的键位——因为 ⌃ b q 在 tmux 里是列窗格， 在 herdr 里是断开会话，印错的 App 会把你踢下线。按连接各选各的， 绝不在背后替你切换。

常见问题

大家最先问的几件事。

需要在我的服务器上装东西吗？

不需要——开箱就是标准 SSH 客户端。mosh、tmux、 herdr 都是可选的。缺哪个，Offhook 会直说、把安装命令摆出来， 你点了才执行。它绝不静默安装，也绝不偷偷换成你没选的那个多路复用器。

它怎么知道 agent 在等我？

在 herdr 上，agent 状态是协议里的一个字段——什么都不用配。 在 tmux 上，App 里提供一行命令装 hook，让 agent 主动上报状态； 不装的话，Offhook 退回到读输出来判断。

支持哪些 agent？

任何跑在终端里的——Claude Code、Codex 等等。状态检测在 herdr 上是协议级、 在 tmux 上靠 hook，所以出了新 agent 通常不需要我们做什么。

App 关掉之后还能叫醒我吗？

老实说：只在会话还活着的时候。Offhook 没有推送服务器——这是"中间什么都没有" 的代价。iOS 最终会挂起连接，在你回来之前状态就不再更新了。

为什么叫 Offhook？

Off-hook 是电话术语里"听筒已摘起、线路激活"的那个状态——图标画的就是它。 而当 agent 替你把活干了，它也就把你 off the hook（解套）了。 中文名就叫「摘机」。
