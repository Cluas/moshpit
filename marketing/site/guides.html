What to read next

If you are choosing a multiplexer, read Using herdr first — it is where Offhook does things no other iPhone terminal does, and it lists its own limits in the same page. If you already live in tmux, start at Using tmux; Offhook attaches to your existing sessions and never restyles them.

If something is already broken, skip to Troubleshooting — it is written symptom first, so you can find your screen rather than guess at a cause.
