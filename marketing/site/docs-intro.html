Start

What Offhook does.

One paragraph, in case you landed here from a search: Offhook is a paid iPhone and iPad terminal for people who run AI coding agents on machines they own. It connects over SSH or Mosh, renders tmux and herdr natively, and — the part no other iPhone terminal does — puts an agent's “I need a human” on your lock screen with the buttons that answer it.

The problem it solves

A coding agent runs for a long time and then stops, because it wants permission to do something. If you are not at the desk, it waits. People come back hours later to an agent that finished its thinking in the first ten minutes and spent the rest of the afternoon holding a question.

Offhook's whole reason to exist is closing that gap: the question reaches your phone, and you answer it without unlocking into anything.

What it is

  • A real terminal. SSH and Mosh, a proper VT emulator, hardware keyboard support, themes and a shortcut bar you build yourself. Not a chat window with a terminal bolted on.
  • A multiplexer client. tmux over control mode, or herdr — the multiplexer written for coding agents — each rendered natively rather than squeezed into a phone-sized fake desktop.
  • An agent console. Which agent is blocked, for how long, and one tap to answer it from the lock screen or the Dynamic Island.

What it is not

  • Not a service. There is no Offhook account, no relay and no cloud — because there is no Offhook server at all. Your phone talks to your machines.
  • Not a file manager. No SFTP browser, no mounting servers into Files. If that is your day, other apps do it well and this one does not do it.
  • Not an agent. Offhook does not think, summarise or write code. It carries your agents' output to you and your keystrokes back.

What it needs from you

A machine you can already SSH into. Everything else is optional: mosh buys roaming, tmux or herdr buy session persistence and the agent features. Offhook tells you what is missing and shows the command — it never installs anything on your host on its own.

The limit worth knowing on day one

There is no push server, so agent state only updates while Offhook is running in the foreground or briefly in the background. Once iOS suspends the connection, the lock screen keeps showing the last thing it saw until you come back. That is the price of nothing-in-the-middle, and it applies to every transport.
