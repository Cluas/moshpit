指南

从头走到尾，按你真正会做的顺序。

文档把每一块单独讲清楚，这里则是把一整件事从头走到尾—— 主机上敲的每条命令、手机上点的每一屏，以及成功之后长什么样。

走一遍

用 iPhone 跑 Claude Code

先让主机连得上、装好 herdr、在窗格里起 Claude Code——或者让 Offhook 开一个隔离的 git worktree 在里面起——然后不解锁手机，直接在锁屏上回它的权限请求。

走一遍

在任何地方连上你的机器

不把 SSH 开到公网也能连上家里或公司的机器：用 Tailscale 这类 WireGuard 组网，加上 Mosh 负责漫游。各自要开哪些端口，以及出门之前怎么验证。

接下来读什么

如果你在挑多路复用器，先读使用 herdr—— 那是 Offhook 做了别的 iPhone 终端都没做的事的地方，而且它在同一页里把自己的限制也列了。 如果你本来就活在 tmux 里，从使用 tmux开始； Offhook 只附着到你已有的会话上，绝不改动它们的样式。

如果已经出问题了，直接跳到排障—— 它是按症状写的，你可以照着屏幕上的样子找，而不用先猜原因。
