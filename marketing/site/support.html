Common questions

Does Offhook need anything installed on my server?

No. It's a standard SSH client out of the box. mosh, tmux and herdr are each optional — if one is missing, Offhook tells you and offers the install command; it never installs anything silently and never falls back to a different multiplexer behind your back.

How does agent status work?

On herdr, agent state is part of the protocol — zero setup. On tmux, a one-line hook install (offered in Settings) lets Claude Code and friends report state; without it, Offhook falls back to output heuristics.

Why does iOS ask for Local Network permission?

Only so SSH/Mosh can reach hosts on your own LAN (192.168.x.x and similar). Deny it and internet hosts still work fine.

Is my data collected?

No — nothing is. See the privacy policy; the App Store label is Data Not Collected.
