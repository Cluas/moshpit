文档

Moshpit 能做什么，以及到哪儿为止。

Moshpit 是给「在自己服务器上跑 AI coding agent」的人用的 iPhone 终端： SSH 与 Mosh、原生 tmux 与 herdr，以及会送到锁屏上的 agent 状态。它没有账号， 也没有自己的服务器——只跟你的主机说话，仅此而已。下面这些页面假设你已经有一台 能 SSH 进去的机器。

开始

Moshpit 是做什么的

一段话说完，以防你是从搜索来的：Moshpit 是一个付费的 iPhone / iPad 终端，给那些在自己机器上跑 AI coding agent 的人用。它通过 SSH 或 Mosh 连接、原生渲染 tmux 和 herdr，而且——这是别的 iPhone 终端都没做的——把 agent 那句「我需要一个人」送到你的锁屏上，连回答用的按钮一起。

SSH 密钥与主机信任

一条连接的两头各有一个信任问题：向服务器证明你是你，以及向你证明服务器是你想连的那台。Moshpit 两件都在设备上做，而且两种秘密都不离开设备。

Mosh 与漫游

mosh 到底给你带来什么、要让它跑起来得开哪些口子、以及屏幕黑着只剩一个光标闪时该怎么办。

连接

在任何地方连上你的机器

跑 agent 的那台机器多半在 NAT 后面——家里的路由器、公司的内网、桌上一台合着盖的 笔记本。这篇讲怎么从手机连回去，而不用把 SSH 挂到公网上。

多路复用器

多路复用器

选 tmux 还是 herdr

多路复用器让你的活儿在断线时不死，也让 Moshpit 有比「一长条滚动」更好的东西可渲染。Moshpit 会说两种。它们不能互换，而且 Moshpit 绝不会偷偷替你换——因为两者的会话毫不相干，换一下等于给你看别人的工作。

多路复用器

使用 tmux

Moshpit 以 tmux 控制客户端的身份 attach 上去，把你的 session、window、pane 用原生 iOS 视图画出来。这页讲清楚三件事：它做了什么、在你服务器上改了什么、以及到哪儿为止。

多路复用器

使用 herdr

herdr 是专门为 CLI coding agent 写的多路复用器。连 herdr 的时候， Moshpit 不用你在主机上装任何东西，就知道每个 agent 在干什么。这一页讲安装、术语、键位、 Agents 区、隔离任务——最后一节讲清楚哪些事它做不到。

Agent

Agent

Agent 状态与锁屏

服务器上的 agent 停下来问你要不要放行。这一页把整条链路讲清楚：那个状态怎么到你手机上、 每个按钮按下去实际往 pane 里打了什么、哪些开关能改它，以及 iOS 会在哪一步把这一切停掉。

Agent

用 git worktree 开隔离任务

给 agent 派活通常意味着人要在机器前：建分支、在里面开个终端、起 agent、敲 prompt。Moshpit 的 New Agent Task 用一个表单做完这四件事——而且是在一个新建的 git worktree 里做，所以你原本 checkout 着的东西一动不动。这是 herdr 的能力，tmux 没有对应物。

Agent

用 iPhone 跑 Claude Code

这个 App 就是为这条路存在的。四步：连上主机、把 herdr 装上、起 Claude Code、 在锁屏上回它的权限询问。这一页里出现的每一条命令和每一句提示，都是 App 里真实的那一份， 不是示意。

输入

输入

键盘与快捷键

键盘上方那条快捷键栏，是 Moshpit 里你按得最多的地方，也完全由你自己排。

输入

滚动与回滚

向上划这个动作，取决于窗格里跑着什么，含义完全不同。在 shell 里它是「让我看看刚才滚过去的」。在抢了鼠标的全屏程序里——agent、vim、htop——它是「你自己滚」。发错了，要么历史够不着，要么你的按键失灵。

输入

剪贴板与粘贴

往终端里粘贴一段多行文本，以前是一种「不小心执行了前三行」的方式。Moshpit 会在对端程序要求时使用 bracketed paste，让一整块以一整块的形式到达。

输入

中日韩与输入法

iOS 上的终端模拟器大多是敲 ASCII 的人写的。切到拼音键盘，裂缝就出来了：正在组词的字看不见、词打到一半光标跳错位置、长按删除不连发。Moshpit 专门为此改了终端引擎。

外观

外观

主题、字体与图标

两套配色并存，而且是刻意分开的：终端主题决定你的 shell 那 16 色长什么样，强调色决定 App 自己的控件长什么样。改一个绝不会动另一个，所以 Solarized 的终端不会逼你用 Solarized 的 App。

帮助

排障

按「你看到什么」编排，而不是按「底层出了什么问题」。每一条都说清楚这屏是什么意思、 下一步做什么。有几条的答案是「什么都不用做，这就是限制」——那几条才是最诚实的。
