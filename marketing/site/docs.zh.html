文档

Offhook 能做什么，以及到哪儿为止。

Offhook 是给「在自己服务器上跑 AI coding agent」的人用的 iPhone 终端： SSH 与 Mosh、原生 tmux 与 herdr，以及会送到锁屏上的 agent 状态。它没有账号， 也没有自己的服务器——只跟你的主机说话，仅此而已。下面这些页面假设你已经有一台 能 SSH 进去的机器。

多路复用器

两个都是可选的——不用它们，Offhook 就是个普通 SSH 客户端。按连接各选各的；绝不会在背后替你切换，因为这两者持有的会话毫不相干。

herdr

使用 herdr

为 coding agent 而生的多路复用器：agent 状态主机零安装、单窗格满宽、在新建的 git worktree 上开隔离任务。也如实写了限制——轮询延迟、独占式直连，以及 herdr 0.7.3 不上报的那些字段。

tmux

使用 tmux

原生控制模式：会话、窗口、窗格都正经渲染。怎么用一行命令装 hook 拿到 agent 状态，以及不装的话你会看到什么。

Mosh

Mosh 与漫游

扛得住 Wi-Fi/5G 切换和丢包的会话、预测回显、UDP 的要求——以及为什么走 Mosh 时 tmux 和 herdr 会退回它们自己的 TUI。

Agent

锁屏

在锁屏上回复 agent

agent 状态怎么到达实时活动和灵动岛、Allow / Deny 和快捷回复实际发送了什么，以及后台的真实限制。

键盘

键盘、主题与快捷键

从终端键库里搭出自己的快捷键栏、用外接键盘，以及换主题、字体、图标和强调色。

排障

有两件事值得先说

Offhook 绝不在你的主机上擅自动手。它不静默装包、不创建你没要求的会话、也不偷偷挂上你没选的那个多路复用器。缺什么就直说，并把命令摆给你看。

没有推送服务器，所以后台就不再更新了。App 进后台后 iOS 会挂起连接，agent 状态停在它最后看到的样子，等你回来才继续。这是「中间什么都没有」的代价，两种传输都一样。
