这一页几乎所有内容都由三条规则决定，知道了它们，大部分现象自己就解释得通。

## 一定连得上

缺依赖绝不阻断连接，只降级。SSH 是保底传输，裸 shell 是保底形态； 任何 banner 后面的终端都完全可用。

![A Connection Error alert reading ](/31-connection-error.jpg)

## 说人话，不甩 stderr

缺什么、影响什么、怎么装，都说清楚。直接把一句 `command not found` 甩到你脸上，那是 bug，不是提示。

## 不背着你做事

不偷装、不偷建会话，也不会因为你选的那个 multiplexer 不在， 就悄悄给你附加另一个。

:::note
<b>先看这三处，再谈别的。</b>

<b>终端顶部那条 banner。</b>同一时间只有一条，永远可以关掉。优先级是固定的： mosh 回程断了 > 漫游中 > 主机降级。

<b>顶栏的传输标签。</b>连着的时候显示 `SSH` 或 `MOSH`， 漫游中显示 `MOSH · roaming`，还有琥珀点的 `reconnecting` 和红点的 `offline`。掉线是看得见的，不会闷着。

<b>mosh 会话里长按这个标签。</b>会出来 **MOSH DIAGNOSTICS**——四个原始计数值， 它就是用来截图发出去的，不是用来看好看的。
:::
