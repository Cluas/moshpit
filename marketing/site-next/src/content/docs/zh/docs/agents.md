## agent 上报状态

用 **herdr** 时，`agent_status` 本来就是每个 pane 上的协议字段，主机上什么都不用装。 用 **tmux** 时，你装的 hook 会往 agent 所在的 pane 上盖四个 `@moshpit_*` 选项。

## Moshpit 去读

只要 Moshpit 还活着，它每 `2s` 扫一遍所有被跟踪的 session。herdr 的控制面轮询在有变化时是 2s，树一安静下来就退到 8s。

## 你这一下打回去

锁屏上的按钮跑在 Moshpit 进程里，不在小组件里。每个按钮往那个 pane 发一串原始字节——Enter、Esc、 Ctrl-C，或者你输的文字。就这些，没有别的。

:::note
<b>这张图里没有 Moshpit 的服务器。</b>你手机上的每一条提醒，都是正在运行的 App 从活着的会话里读出来、 在本机生成的本地通知。这是"中间不放任何东西"换来的，代价你在依赖它之前应该先知道。

把手机揣兜里走人之前，先看 [哪些情况下它不管用](#limits)。
:::
