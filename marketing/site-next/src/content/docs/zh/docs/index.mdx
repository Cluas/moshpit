Moshpit 是给「在自己服务器上跑 AI coding agent」的人用的 iPhone 终端：SSH 与
Mosh、原生 tmux 与 herdr，以及会送到锁屏上的 agent 状态。它没有账号，也没有自己的
服务器——只跟你的主机说话，仅此而已。下面这些页面假设你已经有一台能 SSH 进去的机器。
