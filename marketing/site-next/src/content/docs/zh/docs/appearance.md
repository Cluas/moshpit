## 终端主题

内置 8 套，每套都有真实预览——画廊显示的是实际配色而不只是名字。 主题带完整的 16 色；主题没写明高亮色时，Moshpit 通过提亮推导，而不是瞎猜。

![The Appearance settings screen showing the terminal theme list with a live preview of each theme's sixteen colours](/10-themes.jpg)

编辑器可以做你自己的：每个颜色都能选，结果能以 JSON 导出导入， 这样一套主题可以在设备之间搬（没有账号帮你同步）。

## 字体

内置 7 款等宽字体——JetBrains Mono、Maple Mono、Fira Code、 Source Code Pro、IBM Plex Mono、Hack、Anonymous Pro——外加系统等宽。 字号是带实时样例的滑块，因为手机上的 9pt 和桌面上的 9pt 完全是两回事。

这些字体对 CJK 的覆盖参差不齐；它们缺的字回退到系统字体。 见[中日韩与输入法](/zh/docs/ime)。

## 光标

- **形状**——方块、竖线或下划线，作用于所有会话。
- **颜色**——包括 Mosh 漫游时它会切换成的琥珀色， 这样光标本身就在告诉你链路换了。
- **闪烁**——1.1 秒节奏，跟随 iOS 系统默认。
- **预测轨迹**——Mosh 的预测回显抢在服务器前面显示出来的字符， 会带一条半透明轨迹，直到服务器确认。App 里没有别的东西会告诉你这个差别。

## App 图标与强调色

8 个主屏图标，加一个可自定义的强调色。这两个是刻意分开的选择： iOS 只能切换到构建时就打包进去的图标，所以图标不可能跟随任意强调色—— 假装可以，就意味着要么禁止自定义颜色，要么悄悄挑一个近似的图标。

有一样东西强调色*刻意*碰不到：agent 的状态色。 无论你选什么强调色，琥珀永远是「等你回话」、青色永远是「正在干活」， 在每一屏和锁屏上都一样。会随品味变化的状态色，就不再是状态色了。
