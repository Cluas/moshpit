Moshpit is an iPhone terminal for people who run AI coding agents on their own
servers: SSH and Mosh, native tmux and herdr, and agent state that reaches your
lock screen. It has no account and no server of its own — it talks to your hosts
and nothing else. These pages assume you already have a machine you can SSH into.
