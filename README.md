# Moshpit

**Moshpit is an SSH / Mosh / tmux terminal for iPhone and iPad**, built for developers who run AI coding agents (Claude Code, Codex, and anything else that lives in a shell) on a remote machine.

Its headline feature is **Vibe Island**: a Live Activity that puts a remote agent's status on the Lock Screen and in the Dynamic Island, so a permission prompt can be answered — Allow, Deny, or a quick reply — without unlocking the phone.

- **Website:** https://moshpit.cluas.eu.org
- **Price:** $6.99, one-time — no subscription, no account, no telemetry
- **App Store:** coming soon

This repository doesn't host the app's source — it's here for feedback and support.

## 关于 Moshpit

**Moshpit 是一个为 iPhone 和 iPad 打造的 SSH / Mosh / tmux 终端**，给那些在远程机器上跑 AI coding agent（Claude Code、Codex，或任何跑在终端里的工具）的开发者用。

它的招牌功能是**灵动岛**：一个把远程 agent 状态显示在锁屏和灵动岛上的 Live Activity，权限请求不用解锁手机就能回——Allow、Deny，或者直接回复。

- **官网：** https://moshpit.cluas.eu.org
- **价格：** $6.99，一次性买断，无订阅、无账号、零数据收集
- **App Store：** 即将上架
