# 定价策略

状态：2026-08-07 定稿（同日按"低价入场"修订，并补竞品实查）；
**2026-08-10 修订首发价 $4.99 → $6.99**，见下。目标很朴素：
**先把 $99/年 的开发者账号赚回来**，一切复杂度按这个目标裁剪。

## 一句话版本

**$6.99 首发价一次性买断 → $9.99 标准价 → 站稳后 $12.99/14.99。
美区基准全球自动换算，只涨不降，永不打折。**

### 2026-08-10 修订：首发价改为 $6.99

原来的 $4.99 是 2026-08-08 定的，写下的理由是**第一次上架、心里没底**。
那时就已经标注过"这不是定价理由"，而且下面〈为什么是 $9.99〉一节自己就写着
"定 $4.99 换不来多少转化，反而把买断这个核心卖点显得廉价"。既然文档里的两处
论证互相打架，就按论证走，不按胆怯走：**首发直接 $6.99**。

这一改同时解掉了原先记在"已知代价"里的那笔账——$4.99 正是 Attach 和长尾的
价位，跟一个功能严格弱于我们的对手同价，等于自己放弃"我们更多"的信号。
$6.99 把我们移出那条及格线，又仍在 Secure ShellFish 当年 $6.99 首发的实证
区间内，离品类天花板（ShellFish $29.99、Moshi $199）还有十几倍的伞。

阶梯因此少了一档：原来的"第二档 $6.99"就是现在的起点，下一次动价直接到
$9.99 标准价。安全网没变，还是**涨价随时生效、无需审核**；配套动作也没变：
Promotional Text 明说是 launch price，扳机写在下面的表里，到点就涨。

## 同类产品定价实查（2026-08-07）

| 产品 | 模式 | 价格 | 对我们的含义 |
|---|---|---|---|
| Termius | freemium + 订阅 | Pro **$10/月**（年付 $120/年），免费层无云同步 | 文案里的头号锚点："one Termius month ≈ Moshpit forever" |
| Blink Shell | 订阅（GPL 开源可自编译） | Blink+ **$19.99/年**；Build 另 $7.99/月 | 开源+付费双轨的同型先例；我们买断更简单 |
| Prompt 3 (Panic) | 订阅 | **$9.99/年**（7 天全功能试用） | 订阅已卷到 $9.99/年 —— 对比它第一年不惊艳，**别拿它做锚**，两年起才碾压 |
| Secure ShellFish | 免费 + 一次性解锁 | 现价 **$29.99 lifetime**；**当年 $6.99 首发价 / $9.99 正价起步**，十年 ratchet 上来 | "低价入场 → 逐步涨价"的十年实证，正是我们的路线 |
| **Moshi (getmoshi.app)** | 订阅 + lifetime | **$7.99/月 / $69.99/年 / $199 lifetime** | **agent-first 手机终端的直接竞品**（审批收件箱/锁屏推送/diff）。它证明了这个细分有付费意愿，也给了我们 10–20 倍的价格伞 |
| **Attach**（ssh & native tmux） | **一次性买断，无 IAP** | **$4.99** | **最初的对标产品，正面竞品**。tmux 原生客户端 + 智能键盘 + 20+ 主题 + 语音输入；但 **无 mosh、无 herdr、无锁屏 agent 控制**——通知只到"连接事件"级。评分最近被重置（疑似改名/重上架），和我们一样年轻 |
| Reattach / Shinobi Term / Agentmux / Webmux 等 | 杂 | Reattach Pro $4.99 IAP；Webmux $5–10/座/月 | "iPhone 连 tmux 管 Claude Code"在 2026 已是拥挤赛道——**长尾都挤在 $4.99**，说明该价位是这个品类的"及格线"心智 |
| WebSSH / Cosyra 等 | freemium / 新品 | 低价或未成气候 | 不构成定价约束 |

三条结论：

1. **订阅是品类主流，"一次性买断"是空位**——但对比对象要挑贵的（Termius $120/年、
   Moshi $69.99/年），别碰 Prompt 3 的 $9.99/年。
2. **agent 细分里唯一的直接竞品定价激进**（$199 lifetime）——我们 $6.99–9.99
   一次性是刻意的破局甜点位；品类天花板（ShellFish $29.99、Moshi $199）说明
   长期提价空间巨大，不必现在贪。
3. **Secure ShellFish 就是用户直觉的实证**：$6.99 首发起步、一路涨到 $29.99。
   低价入场不丢人，丢人的是高价入场再打折。
4. **对 Attach（$4.99）打降维战，不打价格战。** 功能面我们严格超集：
   mosh（漫游/高丢包链路，它没有）、herdr、锁屏 Allow/Deny/Reply、灵动岛、
   worktree 一键开任务。
   首发 $6.99 比它高 40%（2026-08-10 修订前是同价 $4.99），**价格本身就在
   替我们说"我们更多"**——原来这句话只能由店页承担。对比表继续把四项能力差
   摆出来，句式是 "everything a tmux client does — plus Mosh, herdr, and
   answering your agents from the lock screen."，但它现在是价差的解释，
   不再是价差的替代品。

## 为什么是 $9.99

1. **定位武器是"对比订阅"，不是"便宜"。** Termius ~$10/月、Blink ~$20/年。
   店页文案的核心句式是：*"less than one month of a subscription — forever."*
   定 $4.99 换不来多少转化，反而把"买断"这个核心卖点显得廉价。
2. **目标用户对 $9.99 无摩擦。** 跑 Claude Code / Codex 的人不为这个数字犹豫；
   herdr 工作台 + 锁屏 Allow/Deny 市面上没有第二家，没有比价对象。
3. **回本线足够低。** Small Business Program（15% 抽成）下美区每份净 ~$8.49，
   含税区混合估 ~$7.5 → **13–15 份回本**。一条像样的 Show HN 就该跨过去。

| 定价 | 每份净收（美区） | 回本份数 |
|---|---|---|
| $4.99 | ~$4.24 | ~24 |
| **$6.99（首发）** | **~$5.94** | **~17** |
| $9.99 | ~$8.49 | ~13 |
| $14.99 | ~$12.74 | ~8 |

首发档与标准档的回本差距只有 ~4 份（$4.99 起步时是 ~11 份）——**首发定价这件事
从来不是回本速度的杠杆**，它只决定第一批买家对这个 App 值多少钱的第一印象。

前提动作：**注册完立刻申请 Small Business Program**，30% 抽成下回本线直接翻倍。

## 价格的时间线（只涨不降）

| 阶段 | 价格 | 触发条件 |
|---|---|---|
| v1.0 首发 | **$6.99** | Promotional Text 明写 "Launch price"，诚实的紧迫感 |
| 涨到 $9.99（标准价） | **回本之后**（≈17 份）且首波曝光潮结束（发帖后 2–4 周）；或累计 ~100 份 / ~15 个 ≥4.5 星评分先到 | 提前 3–7 天公告，收割犹豫者 |
| 涨到 $12.99 | ~30 个 ≥4.5 星评分，或单周自然销量 >50 | 同上 |
| 涨到 $14.99 | agent 工作台成为公认头牌卖点（媒体/帖子反复引用它） | 同上；长期天花板参照 ShellFish $29.99 / Moshi $199，不设上限心态 |

**扳机是纪律，不是意愿。** 到了条件就去 ASC 改价（生效即时、无需审核、
已购用户不受影响）。这一列存在的唯一目的，是让"再等等"没有借口。

原则：**付费买断 App 改价随时生效、无需审核——涨价免费，降价伤已购用户。**
低价入场就是这个模式里"促销"的全部形态；入场之后永远不做"限时五折"，
一次打折就把"这个价格是真的"这份信任烧掉了，而信任正是买断相对订阅的
全部溢价来源。

## 区域策略

- **美区 $9.99 做基准价**，其余区域用 Apple 自动换算的价目点，不手工逐区调。
- **中国大陆首发排除**（APP备案需中国身份证+大陆云主机，调研见 runbook）；
  **欧盟开放**（2026-08-08 定），条件是先完成 DSA trader 认证；
  **法国首发不发**——出口合规答卷按「不发法国」提交，开法国区要重答问卷 + ANSSI 申报。
- 不给低收入区域手动降价：小众专业工具，支持成本全球一致，
  低价区套利下载徒增差评风险。
- 含税区（欧/日）标价含 VAT，净收比美区低 ~10-15%——回本估算里已计入。

## 促销工具箱（买断 App 只有这几样，别发明新的）

1. **促销码**：每版本 100 个、28 天有效。用途优先级：员工 > 媒体/播客 >
   社区活跃反馈者。⚠️ 合规红线：**不得用码换评价**（incentivized reviews
   违反 App Store 条款），送出去就是送，评不评随缘。
2. **手动放行 + 发帖联动**：审核通过后选 Manually release，
   上线当天配 Show HN / X 视频（30 秒：锁屏上 Allow 一个 Claude Code 权限请求）。
3. **涨价预告**：每次涨价前 1–2 周公告，是买断模式里唯一无损的"促销"。

## 反模式（已权衡过，不再重开）

- ❌ 订阅 / 免费+IAP / 功能分层 —— README 已公开承诺买断，反悔即毁品牌；
  且不写 StoreKit 是既定架构决定（真要回头，收据 `originalApplicationVersion`
  可识别老用户，路没堵死，但不主动走）。
- ❌ 打折 / 限时促销 —— 见上，烧信任。
- ❌ 低价冲榜（$0.99/$1.99）—— 榜单对 Developer Tools 类目几乎无意义，
  白白把回本线抬到 70+ 份。

## 监控与决策触发器

- **两个月 < 5 份** → 曝光问题而非价格问题：加帖（HN/X/V2EX/Reddit r/selfhosted、
  r/ClaudeAI），**不降价**。
- **退款率异常**（>5%）→ 看差评找产品问题，仍然不动价格。
- **单帖爆发**（单日 >100 份）→ 提前触发涨价时间线。
- 收入报表看 ASC 的 Payments and Financial Reports，别看 Sales 预估值做决定。
